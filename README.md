# Facebook Clone Website

This project is a **Facebook website clone** created as part of a **Git and GitHub tutorial**. The main purpose of this project is to practice and understand the basic concepts of **Git, GitHub, version control, repositories, commits, branches, and remote repositories** while building a simple web project.

## 📌 About the Project

The Facebook Clone Website is designed to recreate the basic look and feel of the Facebook platform. It is a practice project developed for **educational purposes** and is not intended to be an official version of Facebook.

Through this project, I learned how to manage a project using Git and upload and maintain the project on GitHub.

## 🎯 Purpose

The main objectives of this project are:

* To understand the basics of Git and GitHub.
* To learn how to create and manage a Git repository.
* To practice making commits and tracking changes.
* To understand how to connect a local repository to GitHub.
* To learn how to use Git commands such as `git init`, `git add`, `git commit`, `git remote`, and `git push`.
* To practice creating a basic website using web development technologies.

## 🛠️ Technologies Used

The project is created using basic web development technologies:

* **HTML** – Used to create the structure of the website.
* **CSS** – Used to design and style the webpage.
* **JavaScript** – Can be used to add interactive functionality.
* **Git** – Used for version control.
* **GitHub** – Used to store and manage the project remotely.

## 🚀 Git Commands Practiced

During the tutorial, different Git commands were used to manage the project.

For example:

```bash
git init
```

Initializes a new Git repository.

```bash
git add .
```

Adds the project files to the staging area.

```bash
git commit -m "Initial commit"
```

Creates a commit with a message describing the changes.

```bash
git remote -v
```

Displays the remote repository connected to the local project.

```bash
git push
```

Uploads the committed changes from the local repository to GitHub.
